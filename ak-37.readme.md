```typescript
-getLostItems() / getFoundItems() -
  searchLostItems() / searchFoundItems() - // Full-text search
  createLostItem() / createFoundItem() - // With images
  resolveLostItem() / resolveFoundItem() -
  getRecentLostItems() / getRecentFoundItems();
```

#### `commentsService.ts`

```typescript
-getComments(type, itemId) -
  addComment(type, itemId, content) -
  deleteComment(commentId);
```

#### `statisticsService.ts`

```typescript
-getDashboard() - // Materialized view
  getUserStats(userId) -
  getActivity() - // Last 7 days
  refreshViews(); // Admin only
```
